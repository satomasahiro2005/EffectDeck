App Review notes

Guideline 5 (China): ChatGPT and OpenAI are no longer mentioned in the metadata
or screenshots. On the China mainland storefront (StoreKit countryCode CHN)
the app hides both ChatGPT entries described below.

Remote Control (optional): edits the chain of EffeTune, the free desktop app
(github.com/Frieve-A/effetune, 2.14+), on a computer on the same network.
EffeTune > Settings > Remote Control > Allow remote control shows a QR code;
EffectDeck > Settings > Remote > Scan QR Code reads it. The camera only reads
that code; the local network only reaches the address in it (WebSocket, port
47300-47309). Nothing goes to other servers. Without EffeTune on a computer it
cannot be exercised; the rest of the app does not need it.

SFZ Note Player: SFZ instruments are folders of text and audio samples the user
picks in Files. They are copied into the app and played. Data, not code.

JSFX scripts
EffectDeck can host JSFX, the single-file text effect format used by REAPER.
A script the user brings in becomes an effect in the chain, with its own
sliders and, if it draws, a canvas.

Where scripts come from: only the user, through Plugins > Import JSFX (From
Files, From Link, From Clipboard), Open in / the share-sheet extension, or a
share link (https://effectdeck.nemut.ai/j#...) that carries the script itself.
Those only join the Plugins list and do not run until the user adds them. A
chain link (https://effectdeck.nemut.ai/?p=...) carries no script source.
Write JSFX with ChatGPT (Plugins) and Build with ChatGPT... (Effects) only
open a chatgpt.com link (the ChatGPT app if installed, otherwise the
browser) that carries a short request. The app sends nothing else to ChatGPT.
The user imports a returned script with From Files or From Clipboard. A returned
chain goes in with Presets > Import from clipboard, which reads the clipboard
only when tapped and builds a chain from the app's built-in effects and scripts
already imported; it never imports script code.
There is no catalog or store of scripts; a link is fetched only when the user
taps Import (From Link) or Add (share-sheet extension).
The App Store build ships no scripts, so no JSFX appears in the list until the
user imports one.

How scripts run
- Scripts run in a portable EEL2 interpreter (the WDL/EEL2 engine through the
  open-source ysfx library), built for its portable target: no JIT, no
  executable memory is allocated.
- A script can only process the audio passed to it, draw into its own canvas,
  and read touch and keyboard input on that canvas.
- Scripts have no filesystem access (file_open and file-backed sliders are
  disabled, and import, include(), filename: and data: lines are rejected when
  the script is loaded), no MIDI output, and no network access. EEL2 has no
  networking functions.
- Limits: source up to 1 MB, saved state up to 16 MB, bounded memory. A script
  that repeatedly runs past its real-time deadline is bypassed automatically.
- Scripts cannot change or add app features. They are content for a fixed
  interpreter in the binary.

Relevant guidelines: 2.5.2 (the interpreter ships in the binary; scripts do not
change the app's features) and 4.7 (plug-ins).

How to test
1. Tap Add Effect, switch to Plugins, and tap Import JSFX at the
   top of the list.
2. Either:
   a. Choose From Link and enter
      https://github.com/satomasahiro2005/EffectDeck/blob/main/Tests/Fixtures/JSFX/gain.jsfx
      then tap Import, or
   b. Save the script below as a text file (for example gain.jsfx) in Files
      and choose From Files.
3. "Gain" appears in the Plugins list. Tap it to add it to the chain. With audio
   playing through EffectDeck, its Gain slider (0 to 2) changes the volume.

desc:Gain
author:nemut.ai
slider1:1<0,2,0.001>Gain

@init
g = 1;

@slider
g = slider1;

@sample
spl0 *= g;
spl1 *= g;
