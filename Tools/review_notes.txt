App Review notes

Guideline 5 (China): ChatGPT and OpenAI are no longer mentioned in the metadata
or screenshots. On the China mainland storefront (StoreKit countryCode CHN)
the app hides both ChatGPT entries described below.

Remote Control (optional)
EffectDeck can also edit the effect chain of EffeTune, the free desktop app
whose effects EffectDeck uses (https://github.com/Frieve-A/effetune, 2.14 or
later), running on a computer on the same Wi-Fi network.
- On the computer: EffeTune > Settings > Remote Control > Allow remote control
  shows a QR code.
- In EffectDeck: Settings (top right ...) > Remote > Scan QR Code.
- The camera is used only to read that QR code. The local network is used only
  to connect to the computer address inside it (plain WebSocket on port
  47300-47309). Nothing is sent to any other server, and nothing is recorded.
- Without a computer running EffeTune this feature cannot be exercised; the rest
  of the app works the same without it.

SFZ Note Player
SFZ instruments are folders of text definitions and audio samples. The user
picks a folder in Files (SFZ Library > Import Folder...). The files are copied
into the app and played as samples. They are data, not code.

What it is
EffectDeck can host JSFX, the single-file audio effect script format used by
REAPER. A JSFX script is a plain text file that the user brings
into the app. It becomes an effect in the user's audio chain, with its own
sliders and, if it draws, a canvas inside the app.

Where scripts come from
Only from the user, through:
- Available Effects > Plugins > Import JSFX > From Files
- Available Effects > Plugins > Import JSFX > From Link (a URL the user types or
  pastes)
- Available Effects > Plugins > Import JSFX > From Clipboard (script text the
  user copied)
- Open in from another app, or the EffectDeck share-sheet extension (a file, a
  link or selected text)
- A share link (https://effectdeck.nemut.ai/j#...) that the user taps. The
  script is carried inside the link itself.
Scripts that arrive through Open in, the share-sheet extension or a share link
are only added to the Plugins list. They are not added to the chain and do not
run until the user adds them. A chain link (https://effectdeck.nemut.ai/?p=...)
carries no script source; it can only use scripts already imported on the
device.
Write JSFX with ChatGPT (Plugins) and Build with ChatGPT... (Effects) only
open a chatgpt.com link (the ChatGPT app if installed, otherwise the
browser) that carries a short request. The app sends nothing else to ChatGPT.
The user imports a returned script with From Files or From Clipboard. A returned
chain goes in with Presets > Import from clipboard, which reads the clipboard
only when tapped and builds a chain from the app's built-in effects and scripts
already imported; it never imports script code.
The app does not offer a catalog, store or directory of scripts, and it does not
download scripts on its own. A link is fetched only when the user taps Import
(From Link) or Add (in the share-sheet extension).
The App Store build ships no scripts, so no JSFX appears in the list until the
user imports one.

How scripts run
- Scripts run in a portable EEL2 interpreter (the WDL/EEL2 engine through the
  open-source ysfx library), built for its portable target: no JIT, no
  executable memory is allocated.
- A script can only process the audio passed to it, draw into its own canvas,
  and read touch and keyboard input on that canvas.
- Scripts have no filesystem access (file_open and file-backed sliders are
  disabled, and import, include(), filename: and data: lines are rejected when
  the script is loaded), no MIDI output, and no network access. EEL2 has no
  networking functions.
- Limits: source up to 1 MB, saved state up to 16 MB, bounded memory. A script
  that repeatedly runs past its real-time deadline is bypassed automatically.
- Scripts cannot change or add app features. They are content for a fixed
  interpreter in the binary.

Relevant guidelines: 2.5.2 (the interpreter ships in the binary; scripts do not
change the app's features) and 4.7 (plug-ins).

How to test
1. Tap Add Effect, switch to Plugins, and tap Import JSFX at the
   top of the list.
2. Either:
   a. Choose From Link and enter
      https://github.com/satomasahiro2005/EffectDeck/blob/main/Tests/Fixtures/JSFX/gain.jsfx
      then tap Import, or
   b. Save the script below as a text file (for example gain.jsfx) in Files
      and choose From Files.
3. "Gain" appears in the Plugins list. Tap it to add it to the chain. With audio
   playing through EffectDeck, its Gain slider (0 to 2) changes the volume.

desc:Gain
author:nemut.ai
slider1:1<0,2,0.001>Gain

@init
g = 1;

@slider
g = slider1;

@sample
spl0 *= g;
spl1 *= g;
